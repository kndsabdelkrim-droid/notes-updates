حزمة المطوّر (النسخة 3.1) — لا توزّعها على أحد
==============================================
المجلدات:
 src       واجهة البرنامج وحساباته (هذا ما تعدّله)
 dist      ملفات التحديث الجاهزة: app.enc , app.sig , version.json
 keys      سري جداً: private.pem (التوقيع) و runtime.key (مفتاح الحمولة المشتق)
           انسخه إلى فلاشة أو مكان آمن. لا ترفعه إلى GitHub ولا ترسله لأحد (ولا لأي ذكاء اصطناعي).
           إن ضاع: لن تستطيع إصدار تحديثات تقبلها النسخ الموزعة.
 runtime   يشغّل الأوامر بدل Node.js

عند تعديل ملفات src:
 1) انقر مرتين على pack.bat
 2) ارفع الملفات الثلاثة من مجلد dist إلى مستودع notes-updates على GitHub (استبدل الموجودة)
 3) يتحدّث البرنامج عند الجميع تلقائياً.

التوزيع: ملف NotesDZ-Setup.exe (المثبّت) يوضع في GitHub ← Releases ويحمّله الأساتذة منه.

تنبيه: أي تغيير في ملفات shell أو tools أو package.json يستلزم بناء المثبّت من جديد (يتغير مفتاح الحمولة) وإعادة نشره؛ اطلب ذلك مني.
هذه النسخة بمفاتيح جديدة: من ثبّت نسخة سابقة يثبّت هذه مرة واحدة.
